# where <n> counts the page's `qml` blocks from 1. Read by tests/docs_site.rs;
# an entry that no longer applies fails it, so this list only shrinks.
#
# Reasons:
#   gap:<slug>      `ljos migrate --write` cannot write it in Ljós's API yet.
#                   The slugs are the gaps the migrate work tracks:
#                   imports       an import migrate does not lower
#                   controls      a control Ljos.Controls.Basic does not have
#                   ui-types      a type Ljos.Ui does not have
#                   layout        a layout or delegate migrate does not follow
#                   host-module   the program's own module, registered in Rust
#   host-types      it uses types a Rust program registers, which `ljos check`
#                   has no description of: it must fail there, and only with
#                   `[unknown-type]` errors
#   shows-findings  it shows what the checks find, so `ljos check` fails on it
