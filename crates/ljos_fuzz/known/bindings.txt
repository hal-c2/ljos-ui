# Buckets `ljos-fuzz` has found and that are known: a run reports them and does not fail.
# One per line: the signature, then why it is known, with its scenario or issue.
# A bucket that goes away when Ljós is fixed should go from here too.
# A signature that ends in `*` knows every bucket that starts with what is before it; use
# one only where every such difference is the one cause.
#
# A value's signature is value:context:class. The context is where the difference shows: a
# step (step, step-readonly or step-alias, by what it writes through), or the case being made
# (load, load-handlers when the program has a handler, load-member-alias, alias, alias-to-member),
# or the handlers that wrote the log (onChanged, …). The class is how the values differ:
# nan-ljos (NaN on Ljós only), empty-qt (empty on Qt only), int-range, rounding, text-…, length,
# a-vs-b for values of different kinds; a list or a record is the class of what differs first.
# The class is coarse on purpose, so one cause shows as few buckets; a bucket can hold several
# causes, and its line names them all. observations.json in a repro has the property's type
# and the expression that made the difference as "detail".
