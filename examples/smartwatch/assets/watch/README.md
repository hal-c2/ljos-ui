# Vakt watch assets

Vakt ("watch", as in keeping watch, in Icelandic) is an original cyberpunk
smartwatch made for the smartwatch example. Every file in this directory
except this README and the script is generated by `build_watch.py`. The script
builds the watch from code: a 24-facet lathed case with a side groove, a
smooth bezel with an edge-light channel, faceted lugs and crown guards, a
knurled crown, a pusher, a domed glass and a hinged link strap. It imports no
meshes, images or third-party assets, and it follows no real watch's design.

## Regenerate

```sh
blender -b --factory-startup --python build_watch.py
```

Options go after `--`:

- `--out DIR` writes the files somewhere else (the default is this directory).
- `--render DIR` also renders 1000×1000 EEVEE previews (front, three-quarter
  and side) into `DIR`. The preview renders do not change the exported files.

The output is the same bytes on every run: the script uses no randomness,
fixed object names and fixed export settings, and it puts every object back in
its rest pose after the exporter has sampled the animations. Run it twice and
compare `sha256sum *.glb rig.json` to check.

If Blender fails at startup with `No module named 'math'`, a Python earlier on
`PATH` (for example one installed by uv or pyenv) is hiding the Python that
Blender was built against. Run it as `PATH=/usr/bin:/bin blender …`.

## Files

| file | contents | node | origin (pivot) |
|---|---|---|---|
| `case.glb` | case shell, bezel and its ticks, lugs, spring bars, crown guards, caseback window | `case` | watch centre |
| `crown.glb` | crown: stem, collar, 30-tooth knurl and end cap, along +X | `crown` | where the stem meets the case; turns about X |
| `button.glb` | the pusher below the crown, at -30° (about 4 o'clock) | `button` | its base on the case; slides along `press_axis` |
| `glass.glb` | the domed crystal, mostly clear (`alphaMode` BLEND) | `glass` | watch centre |
| `screen.glb` | the display disc, with UVs (see below) | `screen` | watch centre |
| `link.glb` | one strap link: barrel, chamfered plate and arrow spine | `link` | its hinge; reaches along +Y |
| `watch.glb` | the whole watch under the node `vakt`: both straps chained from `link`, the light strips and the animations below | `vakt` | watch centre |
| `rig.json` | the contract the app's QML is written from (see below) | | |

Each part file holds exactly one node, at that file's origin, and that origin
is the part's pivot. An app places the file under a node at the pivot from
`rig.json`, then turns or moves that node.

The screen's UVs map the disc inscribed in the unit square: (0.5, 0.5) at the
centre and the image's top edge at 12 o'clock. A square picture of a watch
face therefore shows upright, cropped to its inscribed circle. An app can draw
its own disc from `rig.json`'s `screen` instead.

The light strips are not in the part files, so the app can draw them itself
and recolour them or make them pulse. They are in `watch.glb` only, with
emissive materials that use `KHR_materials_emissive_strength`. They are the
edge ring in the bezel, the band in the case's side groove, the ring on the
crown, and a strip on the outside of each lug.

`watch.glb` has these animations:

- `crown_turn`: two seconds, one turn of the crown, meant to loop.
- `strap_flex`: one second, both straps curl in from rest to full flex.
- `turntable`: eight seconds, one turn of the whole watch about +Y, meant to
  loop.

## Axes and units

The units are metres, in glTF axes:

- +Z comes out of the face.
- +Y points to 12 o'clock.
- +X points to the crown at 3 o'clock.

The origin is on the watch's axis, 5.2 mm above the caseback. The case is 46 mm across and 10.6 mm thick, 51.2 mm lug to
lug, and the strap is 22 mm wide. The screen sits 3.4 mm above the origin,
with a radius of 17.8 mm.

Blender works Z-up internally. The script writes the geometry in glTF axes and
millimetres, then turns and scales it into Blender's frame, and the exporter
turns it back: glTF (x, y, z) = Blender (x, z, -y).

## Straps

A strap is a chain of seven `link.glb` copies:

- Link 0 sits at the strap's anchor.
- Each next link sits at (0, `pitch`, 0) in the frame of the link before it.
- Every link is turned about its own X by `rest_deg + flex * flex_deg`, so the
  bends add up and the strap curls back under the wrist.

The bottom strap's anchor is turned 180° about Z, so the same angles curl it
back too. In `watch.glb` the chains are the nodes `strap_top` and
`strap_bottom`, with links `link_top_0` … `link_top_6` and `link_bottom_0` …
`link_bottom_6`.

## rig.json

`rig.json` lists, in glTF axes and metres:

- `axes`, `origin`, `dimensions` and `notes`: the conventions above.
- `parts`: each part's file, node and `pivot`. Each moving part also gives how
  it moves:
  - the crown: `spin_axis`;
  - the button: `press_axis` and `press_depth`;
  - the link: `hinge_axis`.
- `screen`: the display's `center`, `radius`, `normal`, `up` and UV convention.
- `straps`: `pitch`, `links_per_side`, `rest_deg`, `flex_deg`, `hinge_axis`
  and the two `anchors`, each with a position and rotation.
- `light_strips`:
  - `rings`: flat rings, each with a centre, normal, radii and height.
  - `boxes`: axis-aligned boxes, each with a centre and size.

  Each strip has a `color` and an `emissive_strength`, and its centre is
  relative to the watch or to the crown (`center_relative_to`).
- `animations`: the animation names, their durations, whether they loop and
  the nodes each one moves.
- `materials`: the material names and their base colour, metallic and
  roughness. The metallic is kept at 0.35 or below so the case still reads in
  a renderer without an environment map.
