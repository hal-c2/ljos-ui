# Svala GT car assets

Svala ("swallow" in Icelandic) is an original car made for the car-cockpit
example. Every file in this directory except this README and the script is
generated by `build_car.py`. The script builds the car from code (a body
lofted through curved cross-sections, a boolean cut for the wheel arches,
solidify and bevel modifiers with hardened normals, and lathed wheels). It
imports no meshes, images or third-party assets.

The paint is a metallic candy violet. The canopy and roof are one piece of
gloss-black glass, and the sills, nose, tail and diffuser are gloss-black trim.
Full-width light bars cross the nose (cyan) and the tail (magenta-red), and
cyan strips run along the sills and the doors. Only the strips give off light,
so a scene's glow blooms them and leaves the paint alone. `rig.json` gives the
exact colours under `materials`.

## Regenerate

```sh
blender -b --factory-startup --python build_car.py
```

Options go after `--`:

- `--out DIR` writes the files somewhere else (the default is this directory).
- `--render DIR` also renders 1280×720 EEVEE previews into `DIR`. The preview
  renders do not change the exported files.

The output is the same bytes on every run: the script uses no randomness,
fixed object names and fixed export settings. Run it twice and compare
`sha256sum *.glb rig.json` to check.

If Blender fails at startup with `No module named 'math'`, a Python earlier on
`PATH` (for example one installed by uv or pyenv) is hiding the Python that
Blender was built against. Run it as `PATH=/usr/bin:/bin blender …`.

## Files

| file | contents | node | origin (pivot) |
|---|---|---|---|
| `body.glb` | body shell, glass canopy, underbody, wheel wells, interior hint, splitter and diffuser | `body` | car origin |
| `door_left.glb` | left gull-wing door and its window | `door_left` | hinge on the roof line; opens about +Z |
| `door_right.glb` | right gull-wing door, the mirror of the left one | `door_right` | its hinge; opens about +Z |
| `frunk.glb` | front hood lid | `frunk` | hinge at its rear edge; opens about X |
| `trunk.glb` | rear hatch, including the fastback glass | `trunk` | hinge at its front edge (rear of the roof); opens about X |
| `charge_port.glb` | flap on the rear-left quarter panel | `charge_port` | hinge on its front vertical edge; opens about Y |
| `wheel.glb` | one LEFT wheel: tyre, aero rim, brake disc and neon rim ring; axle along X, outer face towards +X | `wheel` | wheel centre |
| `car.glb` | the whole car under the node `svala`, with the light strips and the animations below | `svala` | car origin |
| `rig.json` | the contract the app's QML is generated from (see below) | | |

Each part file holds exactly one node, at that file's origin, and that origin
is the part's pivot. An app places the file under a node at the pivot from
`rig.json` and rotates that node to open the part. The light strips are not in
the part files, so the app can draw them itself and recolour them or make them
pulse. They are in `car.glb` only, with emissive materials that use
`KHR_materials_emissive_strength`.

`car.glb` has these animations, each one second long:
`door_left_open`, `door_right_open`, `frunk_open`, `trunk_open`,
`charge_port_open`, and `wheels_spin` (one turn per second, meant to loop).

## Axes and units

The units are metres, in glTF axes: +Y up, the car's front faces +Z, and the
car's left is +X. The origin is on the ground, centred between the axles. The
car is about 4.6 m long, 2.1 m wide across the rear haunches and 1.2 m tall, with a 2.8 m wheelbase
and a 0.37 m wheel radius.

Blender works Z-up internally, with the front towards -Y. The exporter converts
to glTF axes: glTF (x, y, z) = Blender (x, z, -y).

## rig.json

`rig.json` lists, in glTF axes and metres:

- `parts`: each part's file, node, `pivot`, rotation `axis` and
  `open_angle_deg`. The angle's sign follows the right-hand rule about `axis`.
- `wheel`: the wheel's radius, width and spin axis, plus the four wheel centres.
  Right wheels reuse `wheel.glb` turned 180° about Y (`rotation_deg`), and they
  spin the other way when the car rolls forward (`forward_spin_sign`).
- `light_strips`: axis-aligned boxes with `name`, `center`, `size`, `color`
  and `group`. A strip whose group is a door has its centre relative to that
  door's pivot and moves with the door. The other strips are relative to the
  car origin.
- `animations`: the animation names, their durations and the nodes each one
  moves.
